# TechManualRAG

Мультимодальная RAG-система для поиска по инженерной документации (PDF с текстом, схемами,
таблицами, формулами).

> **Статус:** 🚧 Ранний каркас. Работает извлечение текста из PDF, разбиение на
> перекрывающиеся чанки (`ingest.py`, покрыто тестами), индексация в локальный
> встроенный Qdrant и семантический поиск (`retrieve.py`). В Streamlit-интерфейсе
> есть полный цикл: загрузка PDF, предпросмотр по страницам, кнопка
> «Проиндексировать» и поиск. Изображения, схемы и таблицы пока не извлекаются,
> поэтому мультимодальной система ещё не является.

## Запуск (UI)
```bash
pip install -r requirements.txt
streamlit run app.py
```

Загрузите PDF, нажмите «Проиндексировать» и ищите. Индексация вынесена на отдельную
кнопку, а не запускается при загрузке: эмбеддинг большого руководства занимает время,
а Streamlit перезапускает скрипт при каждом действии в интерфейсе. При первом запуске
скачивается локальная модель эмбеддингов (~130 МБ), дальше она берётся из кэша.

UI и CLI используют один и тот же путь индексации (`retrieve.index_pages`), поэтому для
одного и того же документа получаются одинаковые `chunk_id`, и повторная индексация
обновляет точки, а не дублирует их.

## Извлечение текста из PDF (CLI)

Оффлайн-извлечение текста и разбиение на перекрывающиеся чанки — без запуска UI и
тяжёлых зависимостей (нужен только `PyMuPDF`):

```bash
python ingest.py manual.pdf --json --pages 1 --chunk-size 60 --overlap 10
```

Пример вывода (обрезано):

```json
[
  {
    "page": 1,
    "chunks": [
      "Hydraulic Pump X100 - Overview. Read all safety notices befo",
      "tices before operating the unit."
    ]
  }
]
```

Соседние чанки перекрываются на `--overlap` символов (в примере — `tices befo`),
поэтому контекст не теряется на границе. Полезные флаги: `--pages 1-3` (диапазон
страниц), `--chunk-size`/`--overlap` (размер и перекрытие чанков в символах). Без
`--json` печатается краткий постраничный обзор. При отсутствии файла или не-PDF на
входе команда завершается с ненулевым кодом и понятным сообщением.

Проиндексировать чанки в локальный Qdrant и сразу поискать по ним из терминала
(без Streamlit):

```bash
python ingest.py manual.pdf --index
python retrieve.py "torque spec" --collection manuals
```

`--json` печатает массив `{id, page, text, score}`. Полезные флаги: `--top-k`
(сколько хитов вернуть), `--collection` / `--qdrant-path` (тот же store, что и у
`ingest.py --index`). Если коллекция ещё не создана или запрос пустой, команда
завершается с ненулевым кодом и подсказкой про `ingest.py --index`.

## Дорожная карта: добавление новых руководств
1. Разместить PDF в директории `data/`.
2. Система распарсит PDF (текст, таблицы, схемы).
3. Создаются эмбеддинги (BGE для текста, CLIP для изображений) и сохраняются в Qdrant.
4. Поиск через веб-интерфейс.
